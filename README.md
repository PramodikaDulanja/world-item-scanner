# 🌍 World Item Scanner (Global Visual Intelligence & Sourcing Hub)

A full-stack web application that transforms a simple snapshot of any physical object (watches, bottles, tools, jewelry, antiques) into deep product intelligence, material breakdowns, and live global e-commerce market comparisons.

---

## 🚀 Key Features

- **AI Visual Recognition:** Instantly identifies objects, brands, maker marks, and unique traits using multimodal AI.
- **Global Web & Marketplace Scan:** Automatically crawls global e-commerce, auction platforms, and online stores for matching items.
- **Multi-Currency Pricing Matrix:** Converts foreign store prices (USD, EUR, GBP, JPY, etc.) into local currency equivalents for cross-border price comparison.
- **Material & Era Timeline Card:** Displays estimated manufacturing dates, structural materials, and historical context.
- **Authenticity & Counterfeit Risk Flags:** Analyzes photos for replica or reproduction warning indicators.

---

## 🛠️ Tech Stack

### Frontend

- **Framework:** Next.js (React / App Router)
- **Styling:** Tailwind CSS

### Backend

- **Language & Framework:** Python (FastAPI)
- **Data Validation:** Pydantic
- **Database & Caching:** PostgreSQL & Redis

### AI & Intelligence Layer

- **Multimodal Vision:** Google Gemini Flash/Pro Vision or OpenAI GPT-4o
- **Search & Scraping:** SerpAPI / Google Lens API & BeautifulSoup / Crawl4AI
